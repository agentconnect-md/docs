控制台的所有操作都基于 `https://api.agentconnect.md` 的 REST API，你也可以直接调用这些接口。在 [AgentConnect OSS](/self-hosting) 上，同一套 API 位于 `<your-control-plane-url>/api/v1`。**个人 API 密钥**代表*你本人*的身份和角色，作用域限定在**单个组织**内。

## 创建密钥 [#create-a-key]

<Image src={imgApiKey} alt="创建个人 API 密钥" width={520} />

前往 **个人资料 → API 密钥 → 新建密钥**，填写以下选项：

- **组织**：密钥所属的组织。
- **名称**：可选备注（例如 `ci-runner`）。
- **权限**：密钥可调用的范围：
  - **完全访问**：你的角色允许的所有操作。
  - **只读**：`GET` 接口，以及 [MCP 连接器](/connect-automate/mcp-connector)的只读工具。
  - **Agent 对话**：仅限调用 relay 上的 Agent 对话接口，且只对选中的 Agent 生效。详见 [Agent 对话 API](/connect-automate/agent-chat-api)。
- **Agent**：**全部 Agent** 或 **指定 Agent**。仅在选择 **Agent 对话** 权限时生效。
- **过期时间**：30 / 60 / 90 天、1 年或永不过期（默认 90 天）。

密钥**仅显示一次**，请当场复制保存。之后列表里只会显示末尾几位字符、过期时间和最近使用时间。

密钥只能在控制台中管理。API 密钥无法列出、创建或撤销密钥，也无法创建或删除组织，调用这些接口会返回 `403`。

如果是组织内部的服务需要调用 API，建议为[服务账号](/operate-govern/permissions-overview/members-and-roles#service-accounts)签发密钥，而不是绑定到个人名下。前往 **设置 → 服务账号 → 密钥**，选项与个人密钥相同，只是不需要选择组织。

## 使用密钥 [#use-it]

```bash
curl https://api.agentconnect.md/v1/orgs \
  -H "Authorization: Bearer $AGENTCONNECT_API_KEY"
```

所有资源都按组织隔离，路径位于 `/v1/orgs/{orgId}/…` 下，可用于列出 Agent、读取会话元数据和消息、管理定时任务或触发运行。侧边栏列出了每个接口并附带在线调试面板，原始 OpenAPI 文档链接见上方表格。

由于密钥继承你的角色权限，[查看者](/operate-govern/permissions-overview/members-and-roles)创建的密钥只能读取、不能修改，适合接入监控仪表盘。

在无头客户端中，也可以用同一个密钥为 [MCP 连接器](/connect-automate/mcp-connector)认证：直接将其放入 `Authorization: Bearer` 请求头即可，无需走浏览器 OAuth 流程。

## 撤销 [#revoke]

点击 **撤销** 后密钥立即失效，继续使用该密钥的请求都会收到 `401`。轮换密钥时，请先创建新密钥、更新脚本配置，再撤销旧密钥。

## 其他凭证（补充说明） [#other-credentials-for-completeness]

- **Daemon 密钥**：通过 **添加 Daemon** 生成，用于认证*机器*而非个人。仅在安装命令中显示一次，删除对应 Daemon 时随之失效。
- **机器人令牌**：由各聊天平台签发，详见[机器人](/connect-automate/chat-platforms/bots)。
