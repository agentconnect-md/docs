AgentConnect 提供一个托管的 **MCP 服务器**，地址为：

```
https://mcp.agentconnect.md
```

把它添加到 Claude（或任何支持基于 streamable HTTP 的 MCP 的客户端）后，你的助手就能替你处理组织内的事务：

> _“我们现在有哪些 Agent 在线？”_
> _“这周我们在 Token 上花了多少，按 Agent 分别是多少？”_
> _“每晚的报告定时任务运行了吗——成功了吗？”_
> _“为评审 Agent 创建一个工作日定时任务。”_

## 从 Claude 连接 [#connect-from-claude]

**Claude（claude.ai / 桌面版）**：设置 → **连接器** → **添加自定义连接器**，粘贴 `https://mcp.agentconnect.md`，然后在浏览器中完成：用任一已启用的登录方式登录，**选择要绑定的组织**，查看客户端请求的读取和写入权限，然后点击**授权**。无需复制任何密钥——整个流程是标准的 OAuth 2.1 加动态客户端注册。

**Claude Code**：

```bash
claude mcp add --transport http agentconnect https://mcp.agentconnect.md
```

然后在提示时批准浏览器登录（`/mcp` → 认证）。对于无头环境（CI、服务器），跳过 OAuth，改为附加 [API 密钥](/api)：

```bash
claude mcp add --transport http agentconnect https://mcp.agentconnect.md \
  --header "Authorization: Bearer $AGENTCONNECT_API_KEY"
```

其他任何 MCP 客户端的做法都一样：支持授权码流程就用 OAuth，否则在 `Authorization: Bearer` 请求头中放入个人 API 密钥。

## 读取工具 [#read-tools]

拥有 `mcp:read` 时，助手可以查看：

| 领域     | 工具                                                             |
| -------- | ---------------------------------------------------------------- |
| 身份     | `whoami`                                                         |
| Agent    | `listAgents`、`getAgent`                                         |
| Daemon   | `listDaemons`                                                    |
| 定时任务 | `listCrons`、`getCron`、`listCronRuns`                           |
| 会话     | `listSessions`、`getSession`                                     |
| 分析     | `getUsage`                                                       |
| 集成     | `listIntegrations`、`listBots`、`listAgentHooks`、`listHookRuns` |
| 成员     | `listMembers`                                                    |

`whoami` 返回当前身份、组织和角色。会话工具返回状态、用量和链接——不包含会话记录内容。`listBots` 只返回元数据，绝不返回令牌材料；`getUsage` 包含总量和按 Agent 的细分。会话记录始终留[在你的 Daemon 上](/getting-started/how-it-works)。

## 写入工具 [#write-tools]

当客户端请求且你批准了 `mcp:write` 后，它还可以做出以下更改：

| 领域     | 工具                                       |
| -------- | ------------------------------------------ |
| Agent    | `createAgent`、`updateAgent`、`deleteAgent` |
| Daemon   | `renameDaemon`                             |
| 定时任务 | `upsertCron`、`runCron`、`deleteCron`      |
| 集成     | `setChannelTrigger`、`removeIntegration`   |

写入工具的目录刻意比控制台和 REST API 窄。它不暴露凭证、成员、组织设置、访问控制列表或机器人密钥。

`deleteAgent`、`deleteCron` 和 `removeIntegration` 是破坏性操作。除了客户端自身的批准流程之外，每个操作还要求提供一个与当前实际值完全一致的确认值——Agent 或集成的名称，或定时任务的名称/ID。确认值不匹配或缺失都会被拒绝。

## 权限与信任 [#permissions--trust]

- 一个连接**以你的身份、在一个组织内**行事——即你在授权时选择的组织（或你的 API 密钥所绑定的组织）。要使用另一个组织，请再连接一次。
- OAuth 访问按作用域限定：`mcp:read` 只暴露读取工具，而写入工具需要 `mcp:write`。个人 API 密钥不受作用域限制，因此拥有你账号所允许的全部访问权限。
- 你的**角色和按资源的可见范围原样生效**：这些工具调用的是与控制台相同的 REST 接口，所以查看者的连接器能看到或更改的内容不会超过该查看者在控制台中的权限，[受限资源](/operate-govern/permissions-overview/team-visibility)同样保持隐藏。
- 当某个客户端不应再以你的身份行事时，撤销其 OAuth 连接或个人 API 密钥。
