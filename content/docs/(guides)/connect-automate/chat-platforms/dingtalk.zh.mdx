AgentConnect Cloud 和自托管部署都支持钉钉（中国大陆版）。每个组织用自己的企业内部应用连接机器人。Daemon 通过钉钉的 Stream 模式主动向外连接，因此不需要公网回调 URL。

## 创建应用 [#create-the-app]

登录组织后，在[钉钉开发者后台](https://open-dev.dingtalk.com/)：

1. 在企业内部应用下点击**创建应用**。应用名称只能包含字母、汉字和数字，不能有空格。

   <Image src={imgCreateApp} alt="创建应用面板：填好名称、描述和图标" width={360} />

2. 点击**添加应用能力 → 机器人**并打开机器人配置。给机器人填上 Agent 的名称和图标，钉钉会在聊天里显示它们，AgentConnect 无法替你设置。

   <Image src={imgRobotIdentity} alt="机器人配置：机器人名称和图标" width={640} />

   填写机器人简介和描述，上传消息预览图，保留 **Stream 模式**的消息接收方式，然后点击**发布**。

   <Image src={imgRobotStream} alt="Stream 消息接收模式和发布按钮" width={560} />

3. 在**权限管理**中搜索 `Card.Instance.Write` 并开通，成员就能点按卡片回答 Agent 的问题。这个权限无需审批。不开通时，问题会以带编号的文字发出。

   <Image src={imgPermission} alt="已开通 Card.Instance.Write 权限" width={640} />

4. 在**版本管理与发布**中创建版本，设置谁能看到机器人，然后保存。免审的版本保存后立即上线。之后对应用的每次修改，都要发布新版本才会生效。

   <Image src={imgVersion} alt="新版本，可用范围为全部员工" width={560} />

5. 在**凭证与基础信息**中复制 **Client ID** 和 **Client Secret**。

   <Image src={imgCredentials} alt="应用凭证，具体值已隐藏" width={560} />

## 连接 [#connect-it]

在你的 Agent 上打开**集成 → 添加集成 → 钉钉**，粘贴 Client ID 和 Client Secret，然后点击**连接**。AgentConnect 会先向钉钉校验这对凭证再保存。

<Image src={imgIntegration} alt="添加钉钉集成：填写 Client ID 和 Client Secret" width={640} />

## 使用 [#use-it]

- **单聊**：直接给机器人发消息。一个单聊就是与 Agent 的一个持续会话。
- **群聊**：把机器人加进群并 **@** 它。只有提及机器人的群消息，钉钉才会发给机器人。每次新的 @ 开启一个会话；要接着聊，回复 Agent 的消息即可，回复会自动 @ 机器人。如果想让整个群共用一个会话，在 Agent 的集成卡片上把该群的**会话模式**设为**单一会话**。
- **进度**：Agent 工作时，你的消息上会有一个「🤔思考中」表情，回合结束后消失。回答以 Markdown 发出。
- **文件和图片**：在单聊里给机器人发文件或图片，或在群里 @ 机器人的同时引用一个文件。Agent 也能把工作区里的图片和文件发回来。
- **提问**：Agent 需要你做选择时，会发一张卡片。是/否问题和最多四个选项显示为按钮；五到十二个选项显示为下拉框加**提交**。点选答案后，卡片会向会话里的所有人显示这个答案。

  <Image src={imgQuestionCard} alt="提问卡片：每个选项一个按钮" width={360} />

- **审批**：钉钉没有审批卡片。工具调用需要审批时，由 Agent 编辑者在控制台处理，会话里会收到一条通知。

停止、取消、排队以及修改支持的会话设置，见[会话内命令](/connect-automate/integrations-overview#in-conversation-commands)。

## 说明 [#notes]

- 钉钉标准版每个应用每月可调用 5,000 次 API、接收 3,000 条消息。达到上限后，Agent 会在会话里说明一次，而不是继续回答。更高的钉钉版本额度更高。
- 一个钉钉机器人绑定一个 Agent。删除集成会释放该机器人以便复用（下次选择**使用已有机器人**），不会从钉钉开发者后台删除应用。
- 在**集成 → 消息应用 → 钉钉 → 更换密钥**中更换 Client Secret。机器人的会话不受影响。
