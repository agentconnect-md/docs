## 创建机器人 [#create-the-bot]

1. 打开 [Discord 开发者门户](https://discord.com/developers/applications) → **New Application**，为它命名。
2. 在 **Bot** 下复制**令牌**（如果没有显示，点击 Reset Token）。

## 连接 [#connect-it]

在你的 Agent 上，打开**集成 → 添加集成 → Discord** 并粘贴令牌。AgentConnect 会从中解析出公开的应用 ID，并显示**添加到 Discord**，其中已包含所需的 `bot` 和 `applications.commands` 作用域及权限，包括创建公开线程的权限。

点击**添加到 Discord**，选择服务器，批准邀请，然后点击**连接**。

连接时，AgentConnect 会验证令牌，并自动在 Discord 应用上启用受限的 **Message Content Intent**。你不再需要在设置前手动勾选该选项。如果 Discord 拒绝自动更新，AgentConnect 会在保存集成之前停下来，并提示你手动启用 **Bot → Privileged Gateway Intents → Message Content Intent**。

## 使用 [#use-it]

在机器人可见的服务器频道中提及它，它就会回答；较长的对话会在线程（thread）中继续。你也可以给它发私信。AgentConnect 会把[对话内命令](/connect-automate/integrations-overview#in-conversation-commands)注册为原生的 Discord 斜杠命令。

## 说明 [#notes]

- 如果自动的 Message Content 设置被拒绝，请在开发者门户中手动启用该 intent，然后重新连接。
- 如果机器人无法回复或无法创建线程，使用**设置 → Bots → Discord → 添加到 Discord** 以当前的作用域和权限重新安装它。
- 一个 Discord 机器人绑定一个 Agent；删除集成会释放机器人以供复用。
