QQ **仅支持自托管部署**，AgentConnect Cloud 不提供该集成。Helm chart 默认开启 QQ（`features.qq`）；使用 Docker Compose 时，把 `qq` 加入 [`compose.env`](/self-hosting/docker-compose/configuration#compose-environment) 中的 `FEATURE_FLAGS`，然后重新创建 `web`。开关打开前，集成选择器中不会显示 QQ。

Daemon 会主动向外连接 QQ 官方机器人 API，因此不需要公网回调 URL。

## 创建机器人 [#create-the-bot]

1. 打开 [QQ 开放平台](https://q.qq.com/)，注册账号并创建一个机器人。
2. 在机器人的开发设置中开启私聊和群聊消息，然后复制它的 **AppID** 和 **AppSecret**。
3. 机器人尚未发布时，把你自己的账号和一个测试群加入它的沙箱。未发布的机器人只会在沙箱中回复。
4. 发布机器人之前，把运行 Daemon 所在机器的公网 IP 加入机器人的 **IP 白名单**。机器人上线后，QQ 会拒绝来自其他地址的 API 调用；如果使用动态家用宽带 IP，IP 变化后机器人就会停止回复。

## 连接 [#connect-it]

在 Agent 页面打开**集成 → 添加集成 → QQ**，粘贴 AppID 和 AppSecret，然后点击**连接**。AgentConnect 会先向 QQ 验证这对凭证再保存。

## 使用 [#use-it]

- **私聊**：直接给机器人发消息。回复会随 Agent 生成以 Markdown 格式流式输出。
- **群组**：把机器人加入 QQ 群并 **@ 提及**它。群里所有人共用该群与 Agent 的对话，未提及机器人的普通群聊消息不会进入该对话。
- **图片**：可以给机器人发送 PNG、JPEG 或 WEBP 图片，Agent 也可以把工作区里的图片发回来。其他文件类型暂不支持。
- **提问**：当 Agent 需要你做选择时（例如私聊内容是否可以保存到 Agent 的共享记忆），会发一条带编号选项的消息。引用这条消息并回复编号即可（在群里还需同时 @ 机器人）。
- **审批**：QQ 不支持审批卡片。工具调用需要批准时，由 Agent 的编辑者在控制台处理；在 QQ 仍允许回复的情况下，对话中会收到一条通知。

关于停止、取消、排队以及更改支持的会话设置，参见[对话内命令](/connect-automate/integrations-overview#in-conversation-commands)。

## 说明 [#notes]

- QQ 不会向机器人提供所在群的详细信息，因此对话会列为 `QQ group · <id>` 而非群名。成员也只在 QQ 提供名称时才按名称显示，而私聊中 QQ 不会提供名称。
- QQ 限制机器人针对单条入站消息可发送的回复数量。在群里，Agent 会先确认收到请求、发送有限的进度更新，再给出最终答案。如果答案超限无法发完，AgentConnect 会在聊天中说明，并在会话中保留完整内容。
- QQ 要求机器人的回复必须针对收到的消息，因此控制台无法主动向 QQ 对话发消息，Agent 也无法自行发起新对话。
- 每个 QQ 机器人绑定一个 Agent。删除集成会释放机器人以供复用（下次选择**使用已有机器人**）。
- 在**集成 → 消息应用 → QQ → 更新密钥**中轮换 AppSecret，原有对话不受影响。
