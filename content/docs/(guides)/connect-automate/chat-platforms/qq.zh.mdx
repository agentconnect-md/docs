QQ **仅在自托管部署上**可用，AgentConnect Cloud 不提供。Helm chart 默认开启它（`features.qq`）；在 Docker Compose 上，把 `qq` 加入 [`compose.env`](/self-hosting/docker-compose/configuration#compose-environment) 中的 `FEATURE_FLAGS`，然后重新创建 `web`。在该开关打开之前，QQ 不会出现在集成选择器中。

Daemon 主动向外连接 QQ 的官方机器人 API，因此不需要公网回调 URL。

## 创建机器人 [#create-the-bot]

1. 打开 [QQ 开放平台](https://q.qq.com/)，注册并创建一个机器人。
2. 在机器人的开发设置中开启私聊和群聊消息，然后复制它的 **AppID** 和 **AppSecret**。
3. 机器人尚未发布时，把你自己的账号和一个测试群加入它的沙箱——未发布的机器人在其他任何地方都不会回复。
4. 发布机器人之前，把运行 Daemon 的机器的公网 IP 加入机器人的 **IP 白名单**。机器人上线后，QQ 会拒绝来自任何其他地址的 API 调用；家用宽带的 IP 会变化，机器人在该地址变化后就会停止回复。

## 连接 [#connect-it]

在你的 Agent 上，打开**集成 → 添加集成 → QQ**，粘贴 AppID 和 AppSecret，然后点击**连接**。AgentConnect 会先向 QQ 验证这对凭证，再保存。

## 使用 [#use-it]

- **私聊**——直接给机器人发消息。回复会随着 Agent 的工作以流式方式送达，格式为 Markdown。
- **群组**——把机器人加入 QQ 群并 **@ 提及**它。群里的所有人共享该群与 Agent 的对话；未提及机器人的普通群聊内容不属于这个对话。
- **图片**——给机器人发送 PNG、JPEG 或 WEBP 图片，Agent 也可以把工作区中的图片分享回来。其他文件类型暂不支持。

关于停止、取消、排队以及更改支持的会话设置，参见[对话内命令](/connect-automate/integrations-overview#in-conversation-commands)。

## 说明 [#notes]

- QQ 不会告诉机器人它所在群的任何信息，因此对话以 `QQ group · <id>` 的形式列出，而不是群名。只有在 QQ 发送了名称的地方，成员才会以名称显示，而在私聊中 QQ 从不发送名称。
- QQ 限制机器人针对一条入站消息可以发送的回复数量。在群组中，Agent 会先确认收到请求，发布有限的进度，然后给出答案；如果答案放不下，AgentConnect 会说明这一点，并把完整文本保留在会话中。
- QQ 的回复必须针对机器人收到的某条消息，因此控制台无法向 QQ 对话发送消息，Agent 也无法自行发起对话。
- 一个 QQ 机器人绑定一个 Agent。删除集成会释放机器人以供复用（下次选择**使用已有机器人**）。
- 在**设置 → Bots → QQ → 更新密钥**中轮换 AppSecret。机器人的对话不受影响。
