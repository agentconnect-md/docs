**机器人**是注册在聊天平台上的持久账号，例如 Slack 或 Lark / 飞书应用、Telegram 机器人或 Discord 应用。集成负责将机器人绑定到 Agent，而机器人本身在**集成 → 消息应用**中按平台分标签页统一管理。

已连接的 [Linear](/connect-automate/triggers-automation/linear) 工作区也会显示在同一页面上。由于启用该工作区的所有 Agent 共用同一个工作区身份，这一行显示为*工作区*而非*机器人*。

## 名单 [#the-roster]

名单列出了组织内已注册的所有机器人及其当前绑定的 Agent。删除集成只会释放对应的机器人供其他 Agent 复用，不会将其从聊天平台卸载。

## 频道名单与共享机器人路由 [#channel-roster--shared-bot-routing]

**共享**机器人可以让单个身份背后对接多个 Agent，并将不同频道路由给对应的活跃 Agent。工作原理见[集成概览](/connect-automate/integrations-overview)，完整配置步骤见[一个 Slack 应用按频道对接不同 Agent](/how-to-guides/one-slack-app-across-channels)。

## 删除机器人 [#deleting-a-bot]

只有处于**空闲**状态的机器人才能删除；如果仍有 Agent 在使用它，请先删除对应的集成。删除机器人会清除 AgentConnect 中保存的令牌，而应用本身仍需前往 Slack、BotFather、Discord 开发者门户或 Lark / 飞书开发者控制台自行移除。

Linear 工作区则通过所在行的**断开**操作移除，且无需先解绑各个 Agent：断开会为整个组织移除该工作区（包括你无权查看的 Agent），并撤销在 Linear 的授权。如果 Linear 授权过期或被撤销，可点击同一行的**重新连接**进行修复。
