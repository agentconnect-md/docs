你可以把 Agent 连接到 [Slack](/connect-automate/chat-platforms/slack)、[Microsoft Teams](/connect-automate/chat-platforms/msteams)、[Google Chat](/connect-automate/chat-platforms/googlechat)、[Discord](/connect-automate/chat-platforms/discord)、[Telegram](/connect-automate/chat-platforms/telegram)、[Lark / 飞书](/connect-automate/chat-platforms/lark-feishu)、[钉钉](/connect-automate/chat-platforms/dingtalk)、[企业微信](/connect-automate/chat-platforms/wecom)或[微信](/connect-automate/chat-platforms/wechat)。自托管部署还可以连接 [QQ](/connect-automate/chat-platforms/qq)。每个集成把一个 Agent 绑定到一个机器人和一组对话。

<Image src={imgAddIntegration} alt="为 Agent 选择聊天平台" width={640} />

在 AgentConnect Cloud 上，Slack 可通过内置的**添加到 Slack** 流程直接接入。Lark / 飞书支持推荐的一键配置，Microsoft Teams 由管理员登录一次即可连接。Google Chat、Discord、Telegram、钉钉、企业微信和 QQ 需要填入各自平台的凭证，微信则通过扫码连接。

了解可复用的机器人身份和共享机器人路由，请阅读[机器人](/connect-automate/chat-platforms/bots)。多 Agent 实践示例请参见[一个 Slack 应用按频道对接不同 Agent](/how-to-guides/one-slack-app-across-channels)。

## 管理对话 [#manage-conversations]

机器人发现某个频道、群组或私信后，该对话就会出现在 Agent 的集成卡片上。频道和群组可以设为仅响应提及、响应所有消息，或保持关闭。每个一对一私信都有针对该 Agent 的独立**开启 / 关闭**开关：对所有人可见的 Agent 默认开启，[受限 Agent](/operate-govern/permissions-overview/team-visibility#what-a-restricted-agent-changes) 默认关闭。

把对话设为**关闭**只会静音入站触发，不会移除机器人，也不会影响定时任务和 Agent 交接等主动出站消息。如果想让机器人退出对话，请在聊天平台中管理它的成员身份。
