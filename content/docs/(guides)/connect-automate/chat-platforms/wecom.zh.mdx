企业微信默认关闭。自托管部署用 Helm chart 的 `features.wecom` 开启；在 Docker Compose 上，把 `wecom` 加入 [`compose.env`](/self-hosting/docker-compose/configuration#compose-environment) 中的 `FEATURE_FLAGS`，然后重新创建 `web`。开关打开之前，集成选择器里不会出现企业微信。AgentConnect Cloud 暂未提供。

每个组织用自己企业微信里的智能机器人连接。Daemon 通过智能机器人的长连接主动向外连接，因此不需要公网回调 URL。不支持私有化部署的企业微信。

## 创建智能机器人 [#create-the-smart-bot]

以组织管理员身份登录[企业微信管理后台](https://work.weixin.qq.com/wework_admin/frame#/aiHelper/create)：

1. 创建一个智能机器人，把名称和头像设成你的 Agent 的。聊天里显示的是企业微信中的名称和头像，AgentConnect 无法代为设置。
2. 把机器人的 **API 模式**设为**长连接**。
3. 复制机器人的 **BotID** 和 **Secret**。

一个智能机器人同一时间只允许一条长连接。请给 AgentConnect 一个没有其他程序在用的机器人：第二个程序连上同一个机器人，前一个就会被断开。

## 连接 [#connect-it]

在你的 Agent 上打开**集成 → 添加集成 → 企业微信**，粘贴 BotID 和 Secret，然后点击**连接**。AgentConnect 会先向企业微信校验这对凭证再保存；如果机器人的 API 模式不是长连接，会提示你要改什么。

## 使用 [#use-it]

- **单聊**：直接给机器人发消息。一个单聊就是与 Agent 的一个持续会话。
- **群聊**：把机器人加进群并 **@** 它。只有提及机器人的群消息，企业微信才会发给机器人。企业微信的群没有话题，所以群里所有人共用一个与 Agent 的对话；Agent 怎样组织其中的工作，由 Agent 集成卡片上该群的[**会话模式**](/connect-automate/integrations-overview#session-mode)决定。
- **回复**：答案随 Agent 的书写流式送达，格式为 Markdown。企业微信的一条流式消息最长十分钟，大小也有上限，所以长答案会接着用后续消息发完。
- **文件和图片**：单聊里可以直接给机器人发图片、文件或视频；在群里，把图片和 @ 机器人的文字放在同一条消息里，或者引用一个文件并 @ 机器人。语音消息以企业微信自带的转写文字送达。Agent 也可以把工作区里的图片（PNG、JPEG 或 GIF，不超过 10 MB）和其他文件（不超过 20 MB）发回来。
- **提问**：Agent 需要你单选时会发一张卡片，点一下即可作答。卡片放不下的问题会改成带编号的列表：引用这条消息并回复编号，在群里还要 @ 机器人。
- **审批**：企业微信没有审批卡片。工具调用需要批准时，由 Agent 的编辑者在控制台处理，对话中会收到一条通知。

关于停止、取消、排队以及更改支持的会话设置，参见[对话内命令](/connect-automate/integrations-overview#in-conversation-commands)。

## 说明 [#notes]

- 企业微信不向智能机器人提供群名和成员姓名，所以控制台把对话列为 `企业微信群 · <标记>`，把成员列为 `企业微信成员 · <标记>`；企业微信发来的账号 ID 可读时，则直接显示账号 ID。
- 企业微信没有给智能机器人提供表情回应或“正在输入”提示，所以 Agent 开始工作的第一个信号就是流式回复本身。
- 企业微信限制机器人在每个对话中每分钟最多发 30 条消息、每小时最多 1,000 条。接近上限时，流式刷新会变慢；如果企业微信拒收了答案的一部分，完整文本仍保留在会话中。
- 附件在送达时由 Daemon 取回，保留 24 小时。超过这个时间，或者 Daemon 重启之后，需要重新发送文件。
- 群只有“被 @ 时回复”和“关闭”两种状态，AgentConnect 也无法把机器人移出群，请在企业微信里移除。
- 一个企业微信机器人绑定一个 Agent。删除集成会释放机器人以供复用（下次选择**未使用的企业微信机器人**），但不会删除企业微信里的智能机器人。
- 在**集成 → 消息应用 → 企业微信 → 更换密钥**中更换 Secret。测试新的 Secret 会断开正在运行的机器人，所以 AgentConnect 不做测试；如果更换后机器人不再回复，请从企业微信重新复制 Secret。
