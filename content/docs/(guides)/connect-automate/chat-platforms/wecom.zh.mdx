AgentConnect Cloud 和自托管部署均支持企业微信。每个组织使用各自企业微信里的智能机器人进行连接。Daemon 通过智能机器人的长连接主动向外建连，因此不需要公网回调 URL。暂不支持私有化部署的企业微信。

## 创建智能机器人 [#create-the-smart-bot]

以组织管理员身份登录[企业微信管理后台](https://work.weixin.qq.com/wework_admin/frame#/aiHelper/create)：

1. 填写机器人的名称、简介和头像，与你的 Agent 保持一致。聊天里显示的是企业微信中的名称和头像，AgentConnect 无法代为设置。然后选择 **API 模式**。

   <Image src={imgCreateBot} alt="创建智能机器人：填写名称和简介，选择 API 模式" width={640} />

2. 在 **API 配置**中，将**连接方式**保持为**使用长连接**。

   <Image src={imgApiConfig} alt="API 配置：连接方式为使用长连接，下方是 Bot ID 和 Secret" width={640} />

3. 在**使用模式**中，把**使用方式**从默认的**仅个人使用**改为**多人使用**，并在**可使用成员**中选择允许使用该机器人的成员。

   <Image src={imgUsageMode} alt="使用模式：使用方式为多人使用，并选择可使用成员" width={640} />

4. 点击**保存**，然后在 **API 配置**中复制 **Bot ID**，并点击**点击获取**获取 **Secret**。

一个智能机器人同一时间只允许一条长连接。请给 AgentConnect 分配一个没有其他程序连接的机器人；如果有第二个程序连上同一个机器人，前一个连接会被断开。

## 连接 [#connect-it]

在 Agent 页面打开**集成 → 添加集成 → 企业微信**，粘贴 Bot ID 和 Secret，然后点击**连接**。AgentConnect 会先向企业微信校验这对凭证再保存。如果机器人的连接方式不是长连接，校验会失败并提示需要修改的项。

<Image src={imgIntegration} alt="添加企业微信集成：填写 BotID 和 Secret" width={640} />

## 使用 [#use-it]

- **单聊**：直接给机器人发消息。单聊会作为与 Agent 的一个持续会话运行。
- **群聊**：把机器人拉进群并 **@** 它。企业微信只会把提及机器人的群消息发给机器人。由于企业微信群没有话题，群里所有人共用一个与 Agent 的对话；Agent 如何组织其中的工作，由 Agent 集成卡片上该群的[**会话模式**](/connect-automate/integrations-overview#session-mode)决定。
- **回复**：回答会随 Agent 生成以 Markdown 格式流式输出。企业微信单条流式消息最长持续十分钟且有大小上限，因此较长的回答会分成后续消息发完。
- **文件和图片**：单聊里可以直接给机器人发图片、文件或视频。在群里，把图片和 @ 机器人的文字放在同一条消息里发送，或者引用一个文件并 @ 机器人。语音消息以企业微信自带的转写文字送达。Agent 也可以把工作区里的图片（PNG、JPEG 或 GIF，不超过 10 MB）和其他文件（不超过 20 MB）发回来。
- **提问**：当 Agent 需要你单选时，会发一张卡片，点一下即可作答。卡片放不下的问题会改为带编号的列表，引用这条消息并回复编号即可（在群里还需同时 @ 机器人）。
- **审批**：企业微信不支持审批卡片。工具调用需要批准时，由 Agent 的编辑者在控制台处理，对话中会收到一条通知。

关于停止、取消、排队以及更改支持的会话设置，参见[对话内命令](/connect-automate/integrations-overview#in-conversation-commands)。

## 说明 [#notes]

- 企业微信不会向智能机器人提供群名和成员姓名，因此控制台把对话显示为 `企业微信群 · <标记>`，把成员显示为 `企业微信成员 · <标记>`；企业微信发来的账号 ID 可读时，则直接显示账号 ID。
- 企业微信没有为智能机器人提供表情回应或“正在输入”提示，因此流式回复本身就是 Agent 开始工作的第一个信号。
- 企业微信限制机器人在每个对话中每分钟最多发 30 条消息、每小时最多 1,000 条。接近上限时，流式刷新频率会降低；如果企业微信拒收了部分内容，完整文本仍保留在会话中。
- 附件在送达时由 Daemon 下载并保留 24 小时。超过这个时间，或 Daemon 重启后，需要重新发送文件。
- 群聊只有“被 @ 时回复”和“关闭”两种状态。AgentConnect 无法把机器人移出群，请在企业微信中操作。
- 每个企业微信机器人绑定一个 Agent。删除集成会释放机器人以供复用（下次选择**未使用的企业微信机器人**），不会删除企业微信里的智能机器人。
- 在**集成 → 消息应用 → 企业微信 → 更换密钥**中更换 Secret。因为测试新 Secret 会断开正在运行的机器人，AgentConnect 会直接保存而不做校验；如果更换后机器人不再回复，请从企业微信重新复制 Secret。

## 自托管 [#self-hosting]

自托管部署上企业微信默认关闭。使用 Helm chart 时通过 `features.wecom` 开启；使用 Docker Compose 时，把 `wecom` 加入 [`compose.env`](/self-hosting/docker-compose/configuration#compose-environment) 中的 `FEATURE_FLAGS`，然后重新创建 `web`。开关打开前，集成选择器中不会显示企业微信。
