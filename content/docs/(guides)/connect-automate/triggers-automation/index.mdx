Agents do not need to wait for a chat message. Start work from:

- [GitHub](/connect-automate/triggers-automation/github) issues, pull requests, and review events;
- [GitLab](/connect-automate/triggers-automation/gitlab) issues, merge requests, and comments;
- [Gitea](/connect-automate/triggers-automation/gitea) issues, pull requests, comments, and reviews;
- [Linear](/connect-automate/triggers-automation/linear) issues delegated or mentioned by name;
- [Webhooks](/connect-automate/triggers-automation/webhooks) sent by another system; or
- [Schedules](/connect-automate/triggers-automation/schedules) that run at a time or interval you choose.
