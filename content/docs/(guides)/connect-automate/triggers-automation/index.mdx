Agents don't have to wait for a chat message. You can trigger work from:

- [GitHub](/connect-automate/triggers-automation/github) issues, pull requests, and review events
- [GitLab](/connect-automate/triggers-automation/gitlab) issues, merge requests, and comments
- [Azure DevOps](/connect-automate/triggers-automation/azure-devops) pull requests and comments
- [Gitea](/connect-automate/triggers-automation/gitea) issues, pull requests, comments, and reviews
- [Linear](/connect-automate/triggers-automation/linear) issues delegated to an agent or mentioning it by name
- [Webhooks](/connect-automate/triggers-automation/webhooks) sent by external systems
- [Schedules](/connect-automate/triggers-automation/schedules) running on a time or interval you choose
