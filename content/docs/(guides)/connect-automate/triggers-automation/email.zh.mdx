邮件集成会给 Agent 分配一个**专属邮箱地址**。向这个地址发信或转发邮件，Agent 就会处理并在同一封邮件往来中回复。在任意对话里让它给某人发邮件，它也会用这个地址发出新邮件。

## 添加地址 [#add-an-address]

在 Agent 页面打开**集成 → 添加集成 → 邮件**，填写地址名称。完整地址由该名称与所在工作区的邮件域名组成，例如 `support-bot@mail.example.test`。输入框旁会实时提示名称是否可用。

![在添加集成里选择邮件，填写一个可用的地址名称](/images/email-add-integration.png)

- 名称长度为 3 到 40 个字符，只能包含小写字母、数字、`.` 和 `-`，且必须以字母或数字开头和结尾。
- `admin`、`billing`、`security` 等容易被误认为官方身份的保留名称不可使用。
- 地址不可重复使用。删除集成后，该地址会永久停用，避免已在途的邮件发给其他人。

Agent 的**集成**卡片上会显示这个地址、复制按钮，以及一行说明谁可以向它发信。

![Agent 集成页上的邮箱地址卡片](/images/email-address-card.png)

## 设置谁能写信 [#who-can-write]

点击地址旁的设置按钮，打开**邮件设置**。

![选择“任何人”后的邮件设置界面，以及组织外来信的可见范围](/images/email-settings.png)

**接收来信**

- **组织成员**（默认）：只接收组织成员登录邮箱发来的邮件。成员账号关联的所有登录邮箱都算，例如工作和个人两个 Google 账号。Microsoft 工作或学校账号的邮箱，只有在对应域名已通过组织验证时才算。其他发件人的来信会被拒收，由对方的邮件服务器退信通知。
- **任何人**：接收所有发件人的来信，组织成员仍会按成员身份识别。

无论选择哪一项，来信都必须通过发件人域名校验，伪造发件人的邮件会被拒收。自动邮件（如休假自动回复、邮件列表）会被直接忽略，避免自动回复之间陷入死循环。

**组织外来信谁能看到**

选择**任何人**后，可以指定组织外部来信创建的会话在控制台中由谁可见：

- **可编辑此 Agent 的成员**（默认）：按当前的编辑权限动态生效。编辑者变动后，可见范围也会同步更新。
- **组织内所有人**。
- **指定一位成员**。

组织成员自己发信创建的会话，始终仅该成员本人可见。

## 对话和回信 [#conversations]

每封邮件往来对应一个会话，可在[会话](/operate-govern/sessions)页面查看。后续来信会继续同一个会话，Agent 也能读到之前的邮件记录。

Agent 每轮只回复一封邮件，直接发在同一封邮件往来中：收件人是发信人，并抄送参与过往来的其他组织成员。如果开启了**任何人**，曾在此往来中主动发过信的外部地址也会被抄送，而仅被别人填进 Cc 的地址不会被自动抄送。Agent 会知道哪些地址未被抄送，以便在回信中说明。

只发给组织成员的邮件，如果 Agent 的输出设置开启了署名，文末会附上署名，包含指向 Agent 页面的名字链接和当前会话链接。只要收件人包含组织外部地址，就不会附带署名。

在控制台中，你自己发出的邮件会显示为**你**，其他成员的邮件会显示姓名和头像，与聊天平台的消息一致。非成员地址发来的邮件会直接显示邮箱地址。

附件内容暂不会传给 Agent，但 Agent 可以看到附件文件名。

## 让 Agent 发邮件 [#send-mail]

在任意与 Agent 的对话中（控制台、聊天平台或邮件往来），都可以直接让它发邮件：

> 把发布说明发到 ops@example.test，抄送 dana@example.test。

Agent 会用自己的地址发出新邮件。系统同时会在内部记录一条不会发出的备注，写明是哪个对话发起的、发送原因是什么，方便后续收到回信时接上上下文。

- 由组织成员本人直接提出要求时，Agent 可以发给任意邮箱地址。
- 如果要求来自共享对话中的访客、定时任务、Webhook 运行或委派任务，Agent 只能发给组织成员。
- 单封邮件最多 50 个收件人。

发信不需要额外审批，因为发起请求的成员本人就有权决定发送。需要注意的是，Agent 读到的外部内容（网页、文件或来信）可能会诱导它把已知信息发出去。如果某个 Agent 无法承受这一风险，就不要为它配置邮箱地址。

### 收到回信时 [#answers]

回信进入哪个会话，取决于收件人怎么回复：

- **全部回复**：继续这封邮件的共享对话，会话从 Agent 发出的那封信开始，参与人都能看到其中的每封邮件。
- **仅回复** Agent：为该收件人开启一个独立的私密对话。其他收件人看不到这封回信，Agent 回复某个人时也读不到其他人单独发来的内容。

在每个对话中，Agent 会知道其他收件人里谁已经单独回复、谁还没回复，但看不到他们的具体内容。

如果要汇总所有人的回复，回到当初让 Agent 发信的那个对话里问即可，比如“大家都回了吗？”。由成员发起的邮件，其回信创建的会话默认归该成员可见，因此 Agent 可以在原对话中读取各条回信。其他人在别处询问则无法读取。

## 限制 [#limits]

| | |
| --- | --- |
| 新邮件对话 | 每个发件人每小时最多在单个 Agent 上发起 30 次。 |
| 回信 | 每个地址每天最多 200 封。 |
| 组织外部收件人 | 每个地址每天最多 100 个收件人，回信与新邮件合并计算。 |
| 每封邮件收件人 | 50 个 |

未能发出的回信会保留在会话中，标记为未送达并附带原因。
