Agent 不必等待聊天消息才开始工作。你可以从以下来源启动工作：

- [GitHub](/connect-automate/triggers-automation/github) 的 Issue、Pull Request 和评审事件；
- [GitLab](/connect-automate/triggers-automation/gitlab) 的 Issue、Merge Request 和评论；
- [Gitea](/connect-automate/triggers-automation/gitea) 的 Issue、Pull Request、评论和评审；
- [Linear](/connect-automate/triggers-automation/linear) 中被委派给 Agent 或按名字提及的 Issue；
- 由其他系统发送的 [Webhook](/connect-automate/triggers-automation/webhooks)；或
- 在你选定的时间或间隔运行的[定时任务](/connect-automate/triggers-automation/schedules)。
