控制台中有两个页面用来跟踪模型支出并排查花费去向。

**分析**以图表展示所有已计量的 Token 和费用，任何部署都可以使用，包括未启用账单服务的自托管环境（此时统计的是你自有 Daemon 计量的数据）。**账单**用于管理预付额度余额和账目明细，仅在启用了账单服务的部署中显示。

这两个页面统计的范围并不完全一致。分析页汇总所有已计量的用量，包括运行在你自有 Daemon 上的 Agent。那些 Agent 使用你本地机器上的模型凭证，流量会被计入分析图表，但 AgentConnect 不会收费。只有经过计量的云端用量才会从额度余额中扣除。关于费率以及余额用尽后的表现，见[云端定价](/build-your-team/daemons/manage-daemons#pricing)。

## 账单 [#billing]

### 余额 [#balance]

余额卡片展示当前可用于云端运行的剩余额度，以及组织的账单状态：

- **服务中**：云端部署的 Agent 正常接收模型流量。
- **已暂停**：余额已用尽，云端部署已停止接收新的模型流量。充值后即可恢复。
- **待确认**：组织的访问状态变更尚未在上游确认，因此 AgentConnect 暂不判定为服务中或已暂停。这并非付款异常，稍后会自动恢复正常。

### 充值 [#add-credits]

所有者会看到**充值**按钮，输入金额后会跳转至 Stripe 结账页面。组织内所有成员都可以查看余额和账目明细，但只有所有者可以充值。付款完成后，对应账目行会在收据生成后提供**收据**链接，收据可能会比付款完成稍晚片刻出现。

如果未付款就离开 Stripe 页面，不会产生任何扣费。仍在结算中的付款会显示为待处理而非失败，稍后会自动更新，并在页面顶部以独立横幅提示，与上方的余额状态分开显示。

### 活动 [#activity]

活动图表按你的本地时区，汇总最近 **24h**、**7d**、**30d** 或 **90d** 的账目变化，支持在**用量**和**充值**之间切换。这里适合查看支出发生的时间分布，想了解具体花在了哪些 Agent 或模型上，请看分析页。

### 交易记录 [#transactions]

交易记录表按时间倒序展示账目明细，支持按**用量**或**充值**筛选，并可分页加载更多记录。入账类记录会标注类型（**购买额度**、**调整**、**促销额度**或**退款**），调整类记录可能附带操作人填写的备注。

用量行会以标签形式列出产生支出的 Agent 及其占比。是否显示 Agent 名称取决于你对该 Agent 的访问权限，与 Agents 页面保持一致：所有者可以看到当前组织内的所有 Agent，其他成员只能看到[团队可见范围](/operate-govern/permissions-overview/team-visibility)允许查看的 Agent。无权查看或已删除的 Agent 会合并为一个不带数量的未命名汇总项，与已命名标签的 `+N` 溢出项分开展示。会话的访问权限设置不会影响这里的账单归属。

## 分析 [#analytics]

**分析**以图表展示最近 **24 小时**、**7 天**、**30 天**或 **90 天**的 Token 与费用，支持**按 Agent**、**按 Runtime** 或**按模型**分组。窄屏设备上不提供 90 天视图。点击图例中的某个系列可以隐藏它，再次点击即可恢复，方便聚焦重点数据。

在运行了 Daemon 池的部署中，可以通过**来源**筛选器区分计量入口：

- **全部**：所有已计量的用量，无论是否计费。
- **云端**：由托管池计量的会话，会扣减额度余额。
- **集群**：自托管部署中的对应选项，统计由你自己的 Daemon 池计量、使用自托管模型访问的会话。此处只做统计，不关联 AgentConnect 余额。
- **Daemon**：由你自行连接的 Daemon 计量的会话，仅统计不计费。

来源信息在会话运行时即被记录，因此把 Agent 在自有 Daemon 和资源池之间迁移，只会影响*后续*用量的归类，不会改动历史数据。

## 谁能看到什么 [#who-sees-what]

| 权限项 | 所有者 | 其他成员 |
| --- | --- | --- |
| 查看余额、活动和交易记录 | ✅ | ✅ |
| 查看组织级分析总量和各来源总量 | ✅ | ✅ |
| 查看按 Agent / 模型的细分及支出趋势 | 完整组织用量 | 仅限有权访问的 Agent 和会话的用量 |
| 在账单用量行中看到 Agent 名称 | 组织当前的所有 Agent | 仅限可见范围内的 Agent |
| 充值 | ✅ | ❌ |

所有者可以看到完整的分析归属，包括受限 Agent、其他成员的私密会话以及受提供方权限限制的会话所产生的支出。这些汇总数据不包含会话 ID、标题、会话记录或工具详情；要打开具体会话，仍需符合该会话的[会话可见范围](/operate-govern/permissions-overview/session-visibility)。

对于协作者和查看者，分析归属要求同时拥有该 Agent 和该会话的访问权限。无权归属的支出仍计入组织总量，并在列表中汇总显示为**受限用量**，已归属的 Agent 行加上该汇总项即为组织总量。他们的支出趋势图仅绘制已归属部分，因此加总后可能小于组织总量。各来源总量对所有角色都按整个组织统计。

举个例子：如果某个 Agent 在共享会话中花费了 $4，在另一位成员的私密会话中花费了 $7，它对组织总量的贡献是 $11。所有者会看到全部 $11 都归属到该 Agent；而只能访问该 Agent 和共享会话的协作者，则会看到 $4 归属到该 Agent，另外 $7 归入未归属用量。
