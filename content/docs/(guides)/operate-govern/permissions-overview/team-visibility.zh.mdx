团队可见范围控制哪些**人**能访问某项资源。它与 [Agent 可见范围](/operate-govern/permissions-overview/agent-visibility)相互独立，后者控制哪些 **Agent** 可以相互调用。新建资源默认对全组织可见。改为**指定成员**后，协作者和查看者的访问会受到限制，而组织所有者仍可正常访问。

## 设置可见范围 [#setting-visibility]

支持权限设置的创建和编辑页面中，都有**可见范围**或**团队可见性**选项：

- **所有人**：组织内所有成员都能看到该资源。
- **指定成员**：只有你勾选的当前组织成员，以及所有组织所有者可以看到它。

**指定成员**列表必须至少包含一位当前组织成员。组织所有者即使未被勾选，也可以查看和编辑该资源；把所有者从列表中移出，不会取消其基于角色的权限。成员最终是只读还是可编辑，仍由其[角色](/operate-govern/permissions-overview/members-and-roles)决定。

任何有权编辑资源的人都可以修改它的可见范围。因此被勾选的协作者可以把资源继续分享给其他人，而被勾选的查看者依然只能只读。

## 当成员离开时 [#when-a-member-leaves]

成员退出或被移除后，AgentConnect 会把他们从所有**指定成员**列表中移除。相关资源仍保持**指定成员**状态，且系统会确保至少保留一位当前成员处于选中状态。

## 拥有独立可见范围的资源 [#resources-with-their-own-visibility]

以下资源各自拥有独立的可见范围设置：

- **Agent**
- **Daemon**
- **定时任务**
- [**MCP 提供方和 OpenConnector 连接**](/build-your-team/tools-and-skills)
- [**共享技能来源**](/build-your-team/tools-and-skills)

Agent 和 Daemon 的可见范围相互独立。成员可能看得到某个 Agent，却看不到运行它的 Daemon，但他们无法把 Agent 部署或迁移到自己看不到的 Daemon 上。

其他资源则继承父级资源的访问权限：集成、Webhook 和工作区操作跟随对应的 Agent；定时任务配置和运行历史跟随该定时任务；Daemon 密钥跟随该 Daemon。机器人属于全组织基础设施，不单独设置**指定成员**列表。

在[分析](/operate-govern/billing-and-usage#who-sees-what)页面中，所有者可以看到全组织完整的用量归属；协作者和查看者必须同时有权访问对应的 Agent 和会话，才能看到相应归属。

[会话有自己独立的可见范围规则](/operate-govern/permissions-overview/session-visibility)。即便对应的 Agent 被隐藏，只要你有权查看会话，它的元数据、会话记录、工具详情、关联关系和实时更新依然可读。反过来，组织所有者对资源本身的访问权，也不会让他看到其中的私密会话或受平台权限限制的会话。

## 受限 Agent 会发生什么变化 [#what-a-restricted-agent-changes]

对于未被选中的协作者和查看者，受限的 Agent 会从以下位置消失：Agent 列表和选择器、详情与配置页面、工作区操作、调用控件以及分析归属。组织所有者不受影响。

限制 Agent 的可见范围不会自动隐藏它生成的会话。只要成员通过了会话自身的权限检查，就能继续查看其元数据、会话记录、工具详情、关联关系和实时更新。控制台可能会把 Agent 名称显示为纯文本标签或筛选项，但不会提供链接，也不会授予对该 Agent 本身的任何访问权限。

受限 Agent 的聊天集成也会按对话粒度控制。新发现的频道和私信默认处于**关闭**状态，需要编辑者在 Agent 的集成卡片中逐个开启后，Agent 才会在对应对话中回复。注意，开启某个频道代表信任该频道当前和未来的所有成员，而不是按个人维护的白名单。

当 Agent 从**所有人**改为**指定成员**时，已有频道会保留原来的触发条件，而已知私信会自动切回**关闭**状态。收紧可见范围后，记得检查一下集成卡片。

## 团队可见范围不控制什么 [#what-team-visibility-does-not-control]

团队可见范围不涉及以下边界：

- [角色](/operate-govern/permissions-overview/members-and-roles)：决定成员能执行哪些操作
- [会话可见范围](/operate-govern/permissions-overview/session-visibility)：决定单条会话记录是否私密或跟随平台权限
- [Agent 可见范围](/operate-govern/permissions-overview/agent-visibility)：决定哪些 Agent 可以相互调用
- Runtime 权限模式、仓库访问权限以及平台应用的权限范围
