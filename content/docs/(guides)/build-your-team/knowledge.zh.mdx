知识库为 Agent 团队提供经过审核的共享参考资料，不必把所有文档都塞进每次会话的提示词里。适合存放长期有效的运维手册、架构决策、产品说明和团队规范。同一页面还提供一张单独的卡片，用于管理组织级的外部记忆连接；每个 Agent 仍各自选择[记忆后端和策略](/build-your-team/agents/configure-an-agent#memory)。

<Image src={imgKnowledge} alt="发布经过评审的组织知识" width={680} />

在控制台中打开**知识库**，两个标签页分别对应已发布内容和待审提案：

- **组织**：已发布、带版本历史的 Markdown 条目，供 Agent 按需检索。
- **建议**：组织所有者审阅由 Dreaming 提议的知识库条目和托管技能候选项的地方。

标签页下方是**外部记忆**卡片，列出已批准供 Agent 使用的记忆服务和账号连接。

所有组织成员都能阅读已发布的知识库条目并查看外部记忆连接的元数据。只有组织所有者可以发布、修订、归档或恢复条目，审阅建议，以及管理外部记忆连接。

## 发布知识 [#publish-knowledge]

1. 打开**知识库 → 组织**。
2. 点击**发布知识**，填写标题、Markdown 正文，以及可选的摘要和标签。
3. 发布条目。

编辑条目会生成一个新的不可变修订版本，不会覆盖历史记录。如果不想让 Agent 继续搜到某条内容，可以将其归档；已归档条目随时可查看或恢复。

## 评审 Dream 建议 [#review-dream-suggestions]

[Dreaming](/build-your-team/agents/configure-an-agent#dreaming) 可以从 Agent 近期的工作记录中提炼重复出现的模式，生成知识库条目或托管技能提案。提案不会自动发布：

1. 以组织所有者身份打开**知识库 → 建议**。
2. 审阅提议的 Markdown 内容或完整技能文件树，以及对应的来源会话。
3. 点击**接受**以发布经过批准的不可变修订版本，或点击**拒绝**并将结果记入审阅历史。

如果来源 Daemon 离线，建议仍会留在列表中，只是正文内容暂时不可查看。提案一旦接受，对应的知识库条目或托管技能就会在组织内生效。

已接受的知识库条目会出现在知识库列表中。已接受的托管技能会进入**工具与技能 → 技能库**，但仍需[为每个 Agent 手动启用](/build-your-team/tools-and-skills#enable-tools-and-skills-for-an-agent)。

## 管理外部记忆连接 [#manage-external-memory-connections]

打开**知识库 → 外部记忆**，为组织注册并管理经过批准的记忆服务。组织所有者选择审核通过的插件安装项，填入所需凭证和配置后创建连接。密钥保存后为只写状态，不可再读取。

创建连接不会自动修改任何 Agent 的配置。要使用该连接，请打开目标 Agent 的**记忆**标签页，切换到**外部**，选中对应连接并设置召回和捕获策略。连接负责提供可信的服务端和凭证，Agent 绑定则决定该 Agent 作用域下的身份与读写策略。

完整的部署、连接、绑定与召回验证流程，参见[使用 Mem0 OSS 作为外部记忆](/how-to-guides/external-memory)。

## Agent 如何使用知识库 [#how-agents-use-knowledge]

当任务需要共享背景时，Agent 会按关键词和标签检索已发布的知识库条目。AgentConnect 不会把整座知识库全量注入每次会话，Agent 也不能自行发布或批准条目。

## Dreaming [#dreaming]

Dreaming 配合**托管**记忆使用。在 Agent 的**记忆**标签页中，你可以手动触发 Dream、调整定时计划、审阅整理好的记忆结果，或开启从重复流程中挖掘可复用技能。所有共享知识库和托管技能提案，仍需由组织所有者在**知识库 → 建议**中审核后才能发布。
