Agent 是你在 AgentConnect 中创建和运行的 AI 队友。为每个 Agent 设定明确的职责，选好模型和 Runtime，再把它接入团队日常使用的协作工具。

<Image src={imgAgentsList} alt="Agent 列表：展示每个 Agent 的 Runtime、Daemon、仓库、集成和最近用量" width={900} />

- [创建 Agent](/build-your-team/agents/create-an-agent)，设置初始模型、工作区和 Daemon。
- [配置 Agent](/build-your-team/agents/configure-an-agent)，调整指令、权限、工具和行为参数。
- 开启[助理模式](/build-your-team/agents/assistant-mode)，让 Agent 在每个对话里保持一条上下文，跟进大家交代的事，动手之前先问。
- 在决定采用独立角色、共享路由、并行评审还是委派之前，先对比[多 Agent 工作模式](/build-your-team/agents/multi-agent-work-modes)。
- [配置工作区和仓库](/build-your-team/agents/workspaces-and-repos)，指定 Agent 的代码和文件范围。
- 需要跨会话保留特定知识时，参考[使用 Mem0 OSS 作为外部记忆](/how-to-guides/external-memory)。
- 在[工具与技能](/build-your-team/tools-and-skills)中注册共享的 MCP 提供方和技能源，再按需为每个 Agent 启用。
- 发布经过评审的[知识库](/build-your-team/knowledge)，让每个 Agent 都能按需检索。
- 接入更多触发器和平台之前，先在 [Playground](/build-your-team/agents/playground)（控制台中显示为“试用”）里测试 Agent。
