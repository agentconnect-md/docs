Agent 是你的组织在 AgentConnect 中创建和运维的队友。为每个 Agent 指定一个专注的角色，选择它的模型和 Runtime 设置，并把它连接到团队工作的地方。

<Image src={imgAgentsList} alt="Agent 列表：每个 Agent 的 Runtime、Daemon、仓库、集成和最近用量" width={900} />

- [创建 Agent](/build-your-team/agents/create-an-agent)，并选择它初始的模型、工作区和 Daemon。
- [配置 Agent](/build-your-team/agents/configure-an-agent)，细化它的指令、权限、工具和行为。
- 在选择独立角色、共享路由、并行评审或委派之前，先比较各种[多 Agent 工作模式](/build-your-team/agents/multi-agent-work-modes)。
- [选择 Agent 可以工作的工作区和仓库](/build-your-team/agents/workspaces-and-repos)。
- 当 Agent 需要跨会话保留选定的知识时，参考[使用 Mem0 OSS 作为外部记忆的指南](/how-to-guides/external-memory)。
- 在[工具与技能](/build-your-team/tools-and-skills)下注册共享的 MCP 提供方和技能来源，然后为每个 Agent 启用合适的能力。
- 发布经过评审的[知识库](/build-your-team/knowledge)，让每个 Agent 都能按需查找。
- 在连接更多触发器和平台之前，使用 [Playground](/build-your-team/agents/playground)（控制台中显示为“试用”）测试 Agent。
