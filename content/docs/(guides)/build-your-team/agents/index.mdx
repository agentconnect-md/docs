Agents are the teammates your organization creates and operates in AgentConnect. Give each agent a focused role, choose its model and runtime settings, and connect it to the places where the team works.

<Image src={imgAgentsList} alt="The Agents list: each agent's runtime, daemon, repository, integrations, and recent usage" width={900} />

- [Create an agent](/build-your-team/agents/create-an-agent) and choose its initial model, workspace, and daemon.
- [Configure the agent](/build-your-team/agents/configure-an-agent) to refine its instructions, permissions, tools, and behavior.
- Compare [multi-agent work modes](/build-your-team/agents/multi-agent-work-modes) before choosing independent roles, shared routing, parallel review, or delegation.
- [Choose workspaces and repositories](/build-your-team/agents/workspaces-and-repos) the agent can work in.
- Follow [the guide to using Mem0 OSS as external memory](/how-to-guides/external-memory) when the agent should retain selected knowledge across sessions.
- Register shared MCP providers and skill sources under [Tools & Skills](/build-your-team/tools-and-skills), then enable the right capabilities for each agent.
- Publish reviewed [Knowledge](/build-your-team/knowledge) that every agent can find on demand.
- Use the [Playground](/build-your-team/agents/playground) to test the agent before connecting more triggers and platforms.
