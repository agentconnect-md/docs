A daemon runs agents in an environment you control, with access only to the workspaces, tools, and credentials you choose.

<Image src={imgDaemons} alt="The Infra page: AgentConnect Cloud, the connected daemons, and a daemon group" width={900} />

- [Install the daemon](/build-your-team/daemons/install-the-daemon) and connect it to your AgentConnect organization.
- [Manage daemons](/build-your-team/daemons/manage-daemons) to check status, capacity, and which agents are assigned to each runtime.
- [Upgrade the daemon](/build-your-team/daemons/upgrade-the-daemon) from the console or on the host, and roll back a release if it misbehaves.
- [Daemon groups](/build-your-team/daemons/daemon-groups) keep an agent available when one machine goes down and let its sessions run across multiple machines.
- [Run agents on AgentConnect Cloud](/build-your-team/daemons/manage-daemons#agentconnect-cloud) when you don't want to manage your own machine, with model usage billed at the provider's published rates.
- [Sandbox agent runtimes](/operate-govern/sandboxing) on supported Linux machines, either per agent or as a daemon-wide requirement.
