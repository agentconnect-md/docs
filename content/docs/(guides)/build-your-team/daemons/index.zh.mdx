Daemon 在你掌控的环境中运行 Agent，只访问你指定的工作区、工具和凭证。

<Image src={imgDaemons} alt="基础设施页面：AgentConnect Cloud、已连接的 Daemon 和一个 Daemon 组" width={900} />

- [安装 Daemon](/build-your-team/daemons/install-the-daemon)，并将其连接到你的 AgentConnect 组织。
- [管理 Daemon](/build-your-team/daemons/manage-daemons)，查看运行状态、容量以及每个 Runtime 上分配的 Agent。
- [升级 Daemon](/build-your-team/daemons/upgrade-the-daemon)，支持在控制台或主机本地操作，遇到异常版本时可以回滚。
- [Daemon 组](/build-your-team/daemons/daemon-groups)可在单台机器宕机时保持 Agent 在线，并让会话分布在多台机器上运行。
- [在 AgentConnect Cloud 上运行 Agent](/build-your-team/daemons/manage-daemons#agentconnect-cloud)，无需自己维护机器，模型用量按提供方公开价格计费。
- [为 Agent Runtime 启用沙箱](/operate-govern/sandboxing)，在受支持的 Linux 机器上按 Agent 配置，或设为 Daemon 级的强制要求。
