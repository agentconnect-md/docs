外部记忆让 Agent 可以在你自己运维的记忆服务中保存并检索持久记录。本指南以 [Mem0 OSS](https://github.com/mem0ai/mem0) 搭配 AgentConnect 第一方 Mem0 封装为例。

## 开始之前 [#before-you-start]

部署运维人员需要先完成[可选的 Mem0 配置](/self-hosting/external-memory)。之后你需要准备：

- 一个组织所有者账号
- 一个能访问 Mem0 的在线 Daemon
- 部署时创建的 Mem0 API 密钥

## 1. 创建组织级连接 [#1-create-the-organization-connection]

打开 **知识库 → 外部记忆 → 添加连接**。

选择经过审核的 `ai.mem0.memory.oss — local:mem0-oss` 安装，填入所需凭证及任意非机密 JSON 配置，然后点击 **创建连接**。如果列表中没有这项安装，请先请部署运维人员完成 Mem0 配置。

凭证保存后为只写状态，无法再次查看明文。

<Image src={imgExternalMemoryConnection} alt="注册由运维人员批准的 Mem0 连接" width={560} />

## 2. 绑定 Agent [#2-bind-an-agent]

打开 Agent 的 **记忆** 标签页，选择 **外部**，再选中刚创建的连接。

检索和记录策略可以分别配置：

- **检索 → 每轮**：每轮对话开始前自动检索 Mem0。
- **检索 → 仅工具**：由 Agent 按需主动调用检索工具。
- **记录 → 仅手动**：仅保存明确指定要记住的内容。
- **记录 → 每轮**：在你确认数据边界后，把每轮已送达的对话内容发送到 Mem0。

除非工作流明确需要自动记录，建议先从 **每轮** 检索 + **仅手动** 记录开始。

<Image src={imgExternalMemoryPolicy} alt="选择外部记忆的检索和记录策略" width={900} />

保存配置并等待连接状态变为 **就绪**，再让 Agent 使用外部记忆。

## 3. 测试跨会话检索 [#3-test-recall-across-sessions]

要快速完成端到端验证，可以先临时切到 **记录 → 每轮**：

1. 打开 Playground（控制台中显示为“试用”）发起对话，发送：`Remember that production deploys require a change ticket and two reviewers.`
2. 打开该 Agent 的 **记忆** 标签页，确认新记录已写入。
3. 用同一个 Agent 新建一段 Playground 对话，提问：`What do I need before a production deploy?`

开启 **检索 → 每轮** 后，新会话会拉取刚才保存的记录。记忆按 Agent 隔离，其他 Agent 不会自动共享这条记录。

## 连接状态 [#connection-status]

| 状态 | 含义 |
| --- | --- |
| **连接中** | 正在等待兼容的在线 Daemon |
| **无效** | 请检查连接报错和部署配置 |
| **已降级** | 此前正常的连接暂时不可用 |
| **就绪** | Agent 可以正常检索和记录记忆 |

修改连接配置后会重新执行检查。删除连接前需要先解绑所有 Agent；在 AgentConnect 中删除连接不会删除 Mem0 里已保存的记录。
