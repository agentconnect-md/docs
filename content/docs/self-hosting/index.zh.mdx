AgentConnect OSS 是开源、可自托管的 AgentConnect 服务栈。如果你想在本地评估、并把 Daemon 放在自己的机器上，选择 Docker Compose；如果你需要面向生产形态的部署、让 Agent 运行在隔离的 Kubernetes 沙箱中，选择官方 Helm Chart。

源码可在 [AgentConnect 仓库](https://github.com/agentconnect-md/agentconnect)获取。

## 各项配置在哪里完成 [#what-is-configured-where]

| 配置界面 | 负责的内容 |
| --- | --- |
| `compose.env` 或 Helm values | 镜像、端口、公开 URL、数据库密钥、Vault、连接器以及 Logto 端点 |
| Setup Server | Logto 浏览器认证，GitHub、GitLab、Gitea、Linear、Slack、Google、Lark / 飞书的租户应用，以及部署选项 |
| AgentConnect 控制台 | 组织、Agent、集成、环境、工具和技能 |

Setup Server 是官方支持的配置界面，负责浏览器认证、提供方应用、展示的登录方式以及预设 Agent 的行为。它把部署设置和只写的提供方密钥保存在 PostgreSQL 中。两种拓扑都自带 Setup Server，而且它从不获得公开路由：Compose 把它绑定到回环地址，Helm Chart 不为它创建 Service，因此你要从自己的工作站访问它。[登录](/self-hosting/sign-in)和[提供方应用](/self-hosting/provider-apps)介绍了它所配置的内容。

Agent 执行始终在 Daemon 本地完成。控制平面存储的是协调数据，而不是消息正文、附件字节、工作区或实时的 Agent 会话流。参见[工作原理](/getting-started/how-it-works)。
