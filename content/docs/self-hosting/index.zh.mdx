AgentConnect OSS 是可自托管的开源 AgentConnect 服务栈。如果你想在本地评估、把 Daemon 运行在自己的机器上，用 Docker Compose 即可；如果要做生产部署、让 Agent 运行在隔离的 Kubernetes 沙箱里，请使用官方 Helm Chart。

源码托管在 [AgentConnect 仓库](https://github.com/agentconnect-md/agentconnect)。

## 各项配置在哪里完成 [#what-is-configured-where]

| 配置入口 | 负责内容 |
| --- | --- |
| `compose.env` 或 Helm values | 镜像、端口、公开 URL、数据库密钥、Vault、连接器和 Logto 端点 |
| Setup Server | Logto 浏览器认证，GitHub、GitLab、Gitea、Linear、Slack、Google、Google Chat、Lark / 飞书的租户应用，以及部署选项 |
| AgentConnect 控制台 | 组织、Agent、集成、环境、工具和技能 |

Setup Server 用来配置浏览器认证、提供方应用、可选登录方式以及预设 Agent 的行为，并将部署设置和只写的提供方密钥保存在 PostgreSQL 中。两种部署方式都自带 Setup Server，且不会暴露公网入口：Compose 只绑定回环地址，Helm Chart 不为它创建 Service，需要时直接从本地工作站访问。具体配置见[登录](/self-hosting/sign-in)和[提供方应用](/self-hosting/provider-apps)。

Agent 始终在 Daemon 侧执行。控制平面只保存协调元数据，不存消息正文、附件字节、工作区或实时 Agent 会话流。详见[工作原理](/getting-started/how-it-works)。
