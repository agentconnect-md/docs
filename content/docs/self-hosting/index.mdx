AgentConnect OSS is the open-source, self-hosted AgentConnect stack. Use Docker Compose for local evaluation with daemons on your own machines, or use the official Helm chart for a production deployment where agents run in isolated Kubernetes sandboxes.

The source code is in the [AgentConnect repository](https://github.com/agentconnect-md/agentconnect).

## What is configured where

| Surface                      | Configures                                                                                                                          |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `compose.env` or Helm values | Images, ports, public URLs, database secrets, Vault, connectors, and Logto endpoints                                                |
| Setup Server                 | Logto browser auth, GitHub, GitLab, Gitea, Linear, Slack, Google, Google Chat, Lark / Feishu tenant apps, and deployment options    |
| AgentConnect console         | Organizations, agents, integrations, environments, tools, and skills                                                                |

Use Setup Server to configure browser authentication, provider apps, displayed sign-in methods, and preset-agent behavior. It saves deployment settings and write-only provider secrets in PostgreSQL. Both topologies include it, and it isn't exposed publicly: Compose binds it to loopback, and the Helm chart creates no Service for it, so you reach it directly from your workstation. See [Sign-in](/self-hosting/sign-in) and [Provider apps](/self-hosting/provider-apps) for details.

Agents always run on the daemon. The Control Plane stores coordination data only, not message bodies, attachment bytes, workspaces, or live agent-session streams. See [How it works](/getting-started/how-it-works).
