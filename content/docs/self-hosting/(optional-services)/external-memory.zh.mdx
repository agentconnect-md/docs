---
title: "外部记忆"
icon: Brain
description: "部署 Mem0 OSS，并在需要使用外部记忆的 Daemon 上注册对应的插件。"
---

Mem0 不包含在 AgentConnect 的 Compose 栈中，没有它 AgentConnect 也能正常运行。只有在你需要为 Agent 接入自建的外部记忆服务时，才需要部署 Mem0。

1. 启动 [Mem0 OSS](https://docs.mem0.ai/open-source/setup)，并确保所有需要使用它的 Daemon 都能访问它的 API。
2. 在每台对应的 Daemon 机器上，检出与当前部署一致的 AgentConnect 版本并构建 Mem0 插件。下面的示例把源码克隆到 `/opt/agentconnect`，与第 3 步的配置路径保持一致：

```bash
git clone https://github.com/agentconnect-md/agentconnect.git /opt/agentconnect
cd /opt/agentconnect
git checkout vX.Y.Z
corepack enable
pnpm install --frozen-lockfile
pnpm --filter @agentconnect.md/memory-plugin-mem0 build
```

3. 在每台 Daemon 的 `~/.agentconnect/config.json` 中注册该插件：

```json
{
  "version": 1,
  "memoryPlugins": {
    "mem0-oss": {
      "command": "node",
      "args": ["/opt/agentconnect/packages/memory-plugin-mem0/dist/cli.js"],
      "env": [
        { "name": "MEM0_DIALECT", "value": "oss" },
        { "name": "MCP_TRANSPORT", "value": "stdio" },
        { "name": "MEM0_OSS_BASE_URL", "value": "http://127.0.0.1:8888" }
      ],
      "secretEnv": { "apiKey": "MEM0_API_KEY" }
    }
  }
}
```

按你的实际环境修改脚本路径和 Mem0 地址，然后重启 Daemon：

```bash
npx -y @agentconnect.md/cli restart
```

接下来可以参考[将 Mem0 OSS 用作外部记忆](/how-to-guides/external-memory)，在控制台中创建组织级连接并绑定到 Agent。
