---
title: "External memory"
icon: Brain
description: "Deploy Mem0 OSS and register its plugin wrapper on each daemon that needs external memory."
---

Mem0 isn't bundled with the AgentConnect Compose stack, and AgentConnect runs fine without it. Deploy Mem0 only if you want agents to use an external memory service that you host yourself.

1. Start [Mem0 OSS](https://docs.mem0.ai/open-source/setup) and make sure every daemon that will use it can reach its API.
2. On each of those daemon machines, check out the matching AgentConnect release and build the Mem0 plugin wrapper. The example below clones the repo to `/opt/agentconnect` to match the config in step 3:

```bash
git clone https://github.com/agentconnect-md/agentconnect.git /opt/agentconnect
cd /opt/agentconnect
git checkout vX.Y.Z
corepack enable
pnpm install --frozen-lockfile
pnpm --filter @agentconnect.md/memory-plugin-mem0 build
```

3. Register the wrapper in each daemon's `~/.agentconnect/config.json`:

```json
{
  "version": 1,
  "memoryPlugins": {
    "mem0-oss": {
      "command": "node",
      "args": ["/opt/agentconnect/packages/memory-plugin-mem0/dist/cli.js"],
      "env": [
        { "name": "MEM0_DIALECT", "value": "oss" },
        { "name": "MCP_TRANSPORT", "value": "stdio" },
        { "name": "MEM0_OSS_BASE_URL", "value": "http://127.0.0.1:8888" }
      ],
      "secretEnv": { "apiKey": "MEM0_API_KEY" }
    }
  }
}
```

Update the script path and Mem0 URL to match your setup, then restart the daemon:

```bash
npx -y @agentconnect.md/cli restart
```

Next, follow [Use Mem0 OSS as external memory](/how-to-guides/external-memory) to add the organization connection and bind it to your agents.
