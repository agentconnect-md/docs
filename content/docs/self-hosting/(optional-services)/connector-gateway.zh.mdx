自托管栈内置了一个连接器网关，用于支撑[工具与技能](/build-your-team/tools-and-skills)里的**添加连接器**功能。默认情况下无需任何配置，你就可以浏览连接器目录，并接入通过 API Key、自定义凭证或免鉴权访问的服务。由于网关自带的控制台和管理 API 没有鉴权，它默认只监听本机回环地址，不会对外暴露。

在 Kubernetes 部署中，Helm Chart 会自动为网关挂载独立的持久卷，并从 `agentconnect-secrets` Secret 的 `OPEN_CONNECTOR_ENCRYPTION_KEY` 中读取加密密钥。下文命令均针对 Docker Compose 部署。

不要设置 `OOMOL_CONNECT_ADMIN_TOKEN`。AgentConnect 调用网关时不带 Bearer Token，一旦设置了该变量，连接器目录将无法加载。

如果想为网关的操作 API 启用 Bearer Token 校验，请设置 `OOMOL_CONNECT_RUNTIME_TOKEN`。网关和调用它的 Relay 共用这一个变量，因此两端的运行时鉴权始终同步开启或关闭。

这两个参数属于 Compose 环境变量，仅执行 `docker compose restart` 会沿用旧容器的环境变量，需要重建容器才能生效：

```bash
docker compose --env-file compose.env up -d --force-recreate open-connector relay
```

## 加密存储的连接器凭证 [#encrypt-stored-connector-credentials]

连接器网关把凭证和 OAuth 客户端密钥存在自己的 SQLite 数据卷 `agentconnect_open-connector-data` 中。它独立于 PostgreSQL，`SECRET_CIPHER` 和 Vault Transit 不会对这里生效。在接入任何真实服务前，先为它配置专属加密密钥：

```dotenv
OOMOL_CONNECT_ENCRYPTION_KEY=replace-with-a-stable-random-32-char-secret
```

生成方式和其他密钥一致：

```bash
openssl rand -hex 32
```

如果服务已经在运行，添加密钥后需要重建网关容器：

```bash
docker compose --env-file compose.env up -d --force-recreate open-connector
```

日常备份时请把该数据卷和 PostgreSQL 一并纳入。`docker compose down` 会保留数据卷，`docker compose down --volumes` 则会连同数据库一起删掉。

## OAuth 提供方 [#oauth-providers]

目录过滤按鉴权方式生效。在网关里配好某个服务的 OAuth 客户端之前，只会隐藏它的 OAuth 登录方式；如果该服务还支持 API Key、自定义凭证或免鉴权，它依然会显示在目录中。默认看不到的，只有那些仅支持 OAuth 的服务。

要开启某个服务的 OAuth，需要在网关里配置它的客户端，并把 OAuth 回调路径暴露给浏览器：

1. 为网关分配一个浏览器能访问的公网域名，并写入 `compose.env`：

   ```dotenv
   AGENTCONNECT_PUBLIC_OPEN_CONNECTOR_URL=https://connectors.example.test
   ```

2. 重建网关容器，让它按新域名生成回调地址。如果不重建，发出的授权请求会与下面注册的回调地址不匹配：

   ```bash
   docker compose --env-file compose.env up -d --force-recreate open-connector
   ```

3. 在该域名下**只将** `/oauth/callback` 路径反向代理到网关。第三方服务只需要把浏览器重定向到这里完成授权，其他路径都不应公开。
4. 在第三方平台注册 OAuth 应用，把回调地址（Redirect URI）填为 `<origin>/oauth/callback`。
5. 通过本地端口打开网关控制台 [http://localhost:3100](http://localhost:3100)，填写并保存该服务的 Client ID 和 Client Secret。

> 网关控制台和 `/api` 接口没有任何鉴权，切勿把它们暴露到公网，否则任何人都可能拿到你保存的连接器凭证。

如果网关部署在远程主机上，请用 SSH 端口转发访问，不要直接开放 3100 端口：

```bash
ssh -L 3100:127.0.0.1:3100 operator@host.example
```

## 收窄目录 [#narrow-the-catalog]

| 变量                                | 默认值                                 |
| ----------------------------------- | -------------------------------------- |
| `OPEN_CONNECTOR_PROVIDER_WHITELIST` | 未设置（允许所有服务）                 |
| `OPEN_CONNECTOR_PROVIDER_BLOCKLIST` | 与 AgentConnect 原生集成重叠的服务列表 |

两个变量都接受逗号分隔的服务 ID，且黑名单在白名单之后生效。默认黑名单排除了 GitHub、Slack、Telegram、Discord 和 Lark / 飞书，因为 AgentConnect 已经原生集成了这些平台。只有在你确实需要同时保留两种接入方式时，才需要覆盖默认黑名单。

这两个变量只由控制平面读取，修改后需重建容器生效：

```bash
docker compose --env-file compose.env up -d --force-recreate control-plane
```
