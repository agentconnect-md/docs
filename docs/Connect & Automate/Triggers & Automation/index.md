excerpt: Start agent work from code events, incoming requests, or a schedule.

---

Agents do not need to wait for a chat message. Start work from:

- [GitHub](/docs/github) issues, pull requests, and review events;
- [Webhooks](/docs/webhooks) sent by another system; or
- [Schedules](/docs/schedules) that run at a time or interval you choose.

For a complete example, see [Fast PR reviews with deep review on demand](/docs/fast-and-deep-pr-reviews).
