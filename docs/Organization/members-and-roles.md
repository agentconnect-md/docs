Everything in AgentConnect — agents, daemons, integrations, schedules, keys — belongs to an **organization**. Your first sign-in creates a personal org; create more from the org switcher (top of the left rail → **Create organization**) and switch between them there.

## Members

**Settings → Members & roles** lists everyone in the org. Owners can **Invite** teammates and change roles.

## Roles

| | **Owner** | **Collaborator** | **Viewer** |
| --- | --- | --- | --- |
| See org resources (subject to [sharing](/docs/visibility-and-sharing)) | ✓ | ✓ | ✓ |
| Read sessions, usage, transcripts | ✓ | ✓ | ✓ |
| Create/edit agents, daemons, integrations, schedules | ✓ | ✓ | — |
| Run agents (Playground, Run now) | ✓ | ✓ | — |
| Manage members & roles, org settings | ✓ | — | — |
| See every restricted resource | ✓ | — | — |
| Install/uninstall the GitHub app, manage org bots config | ✓ | ✓ (install/sync) | — |

Viewers are for stakeholders who should watch agents work — sessions, transcripts, usage — without being able to change or trigger anything.

## Profile

The avatar menu → **Your profile** shows your account (name, email, role, member since), lets you edit your display name, hosts your [personal API keys](/docs/api-keys), and signs you out. Sign-in itself is SSO-only (GitHub or Google) — there's no password to manage.
